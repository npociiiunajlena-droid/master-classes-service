# Лабораторная работа 9: Сервис записи на мастер-классы

Проект выполнен на **Laravel 13** с типизированной структурой данных и серверной валидацией.

## Реализованный функционал

- Роли пользователей: `visitor` и `master`.
- Главная страница с меню видов творчества и информацией о компании.
- Страница вида творчества с расписанием мастер-классов.
- Кнопка записи скрыта для неавторизованных пользователей.
- Регистрация с проверкой `email` и `phone`.
- Авторизация по `email/password`.
- Личный кабинет ведущего:
  - список только его мастер-классов;
  - просмотр участников;
  - добавление мастер-класса;
  - редактирование описания и стоимости.
- Ограничения по расписанию:
  - слоты только `09:00`, `11:00`, `13:00`, `15:00`;
  - продолжительность 2 часа;
  - занятые слоты ведущего блокируются.
- Ограничения записи участника:
  - нельзя записаться дважды на один мастер-класс;
  - нельзя записаться на то же время/дату;
  - запись только при наличии свободных мест.
- Страница подтверждения записи (подтвердить/отменить) с последующим редиректом и сообщением.

## Типизация данных в БД

Используются типы:
- `DATE` для даты занятия;
- `TIME` для времени;
- `DECIMAL(10,2)` для стоимости;
- `SMALLINT UNSIGNED` для размера группы;
- `ENUM('visitor','master')` для роли;
- внешние ключи и уникальные индексы для целостности данных.

## Развёртывание через phpMyAdmin (как требует задание)

1. Откройте phpMyAdmin.
2. Импортируйте файл:
   - `database/sql/master_classes_lab9.sql`
3. Проверьте `.env`:
   - `DB_CONNECTION=mysql`
   - `DB_HOST=127.0.0.1`
   - `DB_PORT=3306`
   - `DB_DATABASE=master_classes_service`
   - `DB_USERNAME=root`
   - `DB_PASSWORD=`
4. Установите зависимости:
   ```bash
   composer install
   ```
5. Запустите приложение:
   ```bash
   php artisan serve
   ```

Альтернатива: вместо импорта SQL можно создать БД в phpMyAdmin и выполнить:
```bash
php artisan migrate --seed
```
